Random Password Generator - README

Description:
-------------
This is a simple Python script that generates a secure random password based on the length specified by the user. 
The password meets basic security requirements to ensure it includes a mix of characters for better strength.

Features:
----------
- User-defined password length
- Ensures each password contains at least:
  - One uppercase letter
  - One lowercase letter
  - One digit
  - One special character
- Handles invalid input (e.g., non-numeric values or lengths less than 4)
- Uses only built-in Python libraries (no installation required)

Requirements:
--------------
- Python 3.x installed on your system

How to Use:
------------
1. Open the terminal or command prompt.
2. Navigate to the folder where the script is saved.
3. Run the script using the following command:
   python password_generator.py
4. Read the password requirements displayed on screen.
5. Enter your desired password length (must be 4 or greater).
6. The script will output a randomly generated secure password.

Example:
---------
Password Requirements:
- Minimum length: 4 characters
- Must include at least one lowercase letter
- Must include at least one uppercase letter
- Must include at least one digit
- Must include at least one special character

Enter desired password length: 10
Generated password: A2&fRx@z8Q

File Contents:
---------------
- password_generator.py : The main script file
- README.txt            : This explanation file

Notes:
-------
- For stronger security, use passwords with a length of 12 or more characters.
- Generated passwords are not stored or saved by the script.
- You can generate multiple passwords by re-running the script.
